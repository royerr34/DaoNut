# DaoNut

DaoNut enables decentralized, event-driven data processing through asynchronous node clusters and autonomous software agents.

DaoNut is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- DaoNut enables decentralized, event-driven data
- processing through asynchronous node clusters
- and autonomous software agents

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoNut.git`
2. `cd DaoNut`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DaoNut, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
